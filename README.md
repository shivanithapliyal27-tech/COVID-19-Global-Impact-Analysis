# COVID-19 Global Impact Analysis

## Project Overview

This project focuses on analyzing the global impact of COVID-19 using Python, SQL Server, and Power BI. It explores confirmed cases, deaths, recoveries, active cases, monthly trends, and country-wise and continent-wise comparisons.

The project transforms raw COVID-19 data into meaningful insights through data cleaning, analysis, and interactive visualizations.

## Objectives

- Analyze global COVID-19 confirmed cases and deaths.
- Compare recovery and active cases across countries and continents.
- Identify countries with the highest number of cases and deaths.
- Examine monthly COVID-19 case and death trends.
- Calculate and compare recovery and death-related rates.
- Build an interactive Power BI dashboard.
